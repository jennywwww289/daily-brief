### Codex CLI 預設啟動常駐、自動更新的背景 daemon，社群要求改成選用

**發生什麼：** 【事實】openai/codex 的 GitHub issue #48195（2026-09-25 開立）寫道：自 0.157.0 起，只要開啟互動式 codex session，就會啟動一個不隨視窗關閉的背景 daemon，把約 374 MB 的套件複製到 `~/.codex/packages/app-server-daemon/`，並啟動每小時檢查更新的 updater。回報者要求 `daemon_auto_start` 預設關閉，並指出 `daemon stop` 不會停止 updater。Hacker News 頁面目前 493 分、253 則留言。
**背景：** 【事實】討論串內有人貼出 9/28 一個標題為「codex: disable daemon auto-start by default」的 commit 引用此 issue，回報者自己的暫時做法是執行 `codex features disable daemon_auto_start`。
**影響誰：** 【推測】有裝 Codex CLI 的人，建議自己檢查背景程序與 `~/.codex` 目錄大小；你主要用的 Claude Code 不在此議題內。
**我不確定的地方：** 【不確定】那個 commit 是否已進入官方釋出版本，我只在 issue 討論串看到引用，沒有核對 openai/codex 的版本紀錄；留言中對動機的臆測（例如「像惡意程式」）是網友意見，沒有證據。
